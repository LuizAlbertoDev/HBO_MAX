# Interface de streaming — projeto de estudo

Reprodução educacional de elementos visuais de uma plataforma de streaming, criada para praticar HTML, CSS e responsividade.

## Tecnologias

- HTML5
- CSS3
- Layouts e estilização responsiva

## Arquivos principais

- `index.html`: página inicial.
- `signin.html`: interface de entrada.
- `assets/css/`: estilos.
- `assets/images/`: imagens do exercício.

## Como executar

Abra `index.html` no navegador. Não é necessário instalar dependências.

## Limitações

Este repositório é um exercício visual. Não oferece assinatura, reprodução real de vídeos, autenticação ou vínculo oficial com a HBO ou a Warner Bros. Discovery. Os nomes e materiais visuais pertencem aos respectivos titulares.
